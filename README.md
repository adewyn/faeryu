# faeryu music site

Edit the data at the top of `build.py` (releases, links, bio), then run:

    python3 build.py

Live at https://adewyn.github.io/faeryu — rebuild with:

    FAERYU_SITE=https://adewyn.github.io/faeryu python3 build.py

When the own domain is bought, use it as FAERYU_SITE instead (this also writes the CNAME file).
